从人工选择到公开图库

本站基于已保存的会议图库人工选择快照，保留图片 ID 和论文 ID。每张图片先校验 SHA-256 与原分类记录一致，再转换为用于浏览的 WebP 图片，另生成缩略图以减少首屏流量。浏览图与缩略图共享同一个数据 ID，来源信息随图保存。

主类别与副类别

主类别表示整张图最主要的科学沟通目的；副类别表示同图还包含的、具有实质内容的其他沟通目的，可以没有，也可以多个。模型优先查看原图，图注和标题仅提供上下文。普通方框和箭头不自动意味着流程图，绘制在坐标轴上的图也不自动属于数据展示图。

  • 框架总览：完整方法的高层组成与主要联系。
  • 流程图：强调顺序步骤、分支、决策或迭代。
  • 架构图：强调模块、网络层、接口和内部组成。
  • Benchmark 图：评测任务、场景、基准构建或评测协议。
  • 综述图：研究领域分类、文献脉络和技术演进。
  • 概念图：解释概念、机制、原理、现象或问题。
  • 比较图：比较方法、结构、假设或范式的差异。
  • 结果对比：实验表现、消融、效率或生成结果比较。
  • 数据统计：数据集构成、计数、频率、比例和覆盖度。
  • 数据展示图：趋势、关联、嵌入、注意力或空间关系等。
  • 其他：能够辨识、但不属于上述类别的内容。
  • 待确认：图像证据不足，不能可靠判断。

目录与追溯

公开目录位于 data/figures.json；assets/figures.js 提供离线兼容版本。images/{会议}/final 保存浏览图，images/{会议}/thumbs 保存缩略图。每条记录包括原图校验值、图注、论文作者、来源和主副类别，不包含本机路径、API 密钥、PPT 或私有质量评审数据。

限制

页面展示所整理会议记录的年份与接收信息，不重新鉴定论文归属。自动裁剪和模型分类可能有误，请通过原论文核对，并使用个人分类修正或提交 Issue。个人分类不自动写回公开仓库，需要维护者更新目录。
