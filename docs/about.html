ABOUT THE COLLECTION

从好的绘图，学会更好的表达。

科研图鉴收录人工挑选的 ICLR、CVPR、ACL 和 EMNLP 2026 科研图片，保留论文标题、作者、图注、摘要及来源链接，通过主类别和多个副类别帮助研究者寻找设计参考。

这份图鉴有什么？

  • 2,831 张图：ICLR 1,017、CVPR 660、ACL 983、EMNLP 171，关联 2,117 篇论文。
  • 按会议、内容类别、主副类别范围、主会/Findings 和已知录取类型筛选。
  • 检索论文标题、作者、图注、摘要；高清图片浏览、缩放、键盘切图。
  • 收藏、灵感笔记、个人分类修正，支持 JSON 导入和导出、BibTeX 引用及分享链接。
  • 中英文界面、明暗主题、手机布局、无需账号的本地保存。

关于来源和版权

图片来自所链接论文的公开版本，原始图片、论文文字及研究成果的权利归论文作者、出版者或其他权利人所有。本项目不将图片统一声明为 CC BY，也不提供超出原论文许可的使用授权。下载图片或参考其表达时，请注明原论文，并检查相应原始许可。

如果您是权利人，需要补充署名、纠正信息或下架图片，请在 GitHub 提交 Issue，提供图片 ID、原论文链接及相关说明。

分类与数据

图片经过人工挑选，JEV/CLEF 结合图像、图注和论文标题标注内容类别；可用的已导出人工修正优先。类别属于检索标签，不代表论文质量、图的编辑性或接收等级。录取信息只显示原记录已明确标注的部分，没有的信息不推断。网页中的个人修正只影响您自己的浏览器，导出后可以保留或分享。

隐私与离线使用

图库没有后端，没有统计脚本，不上传收藏或笔记。个人记录保存在当前浏览器的 localStorage，不会因刷新清空；更换域名或设备前请导出备份。图片与目录在本站保存。可直接打开下载仓库中的 index.html，也可启动本地 HTTP 服务。字体使用 Google Fonts，无法访问时自动回退系统字体。
